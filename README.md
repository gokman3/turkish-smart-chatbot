# 🤖 Turkish Smart ChatBot (v1.0) - Developed by Gökmen

This intelligent Turkish virtual assistant is developed by **Gökmen**, a Computer Engineering student at **Ankara Yıldırım Beyazıt University (AYBU)**. Built with **Vanilla JavaScript** and **Fuse.js**, the project features advanced fuzzy search logic to understand natural language and tolerate typos, all wrapped in a sleek, modern glassmorphism interface.

---

### 🚀 Key Features & Technologies
- **Intelligent Matching:** Utilizes `Fuse.js` for fuzzy searching, ensuring it understands user queries even with typos (e.g., matching "nasilsin" as "nasılsın").
- **Performance:** Optimized to process a massive dataset of **20,000+ Turkish entries** with zero performance lag.
- **Dynamic Commands:** Built-in logic for real-time **Time/Date** updates and a functional **Math Solver**.
- **Modern UI:** Features a dark-themed, responsive design with frosted glass effects and smooth CSS animations.
- **Tech Stack:** HTML5, CSS3 (Custom Variables & Flexbox), ES6+ JavaScript, and Fuse.js library.

---

### 📦 Installation & How to Run
Since this is a client-side web application, it does not require any server-side installation or dependencies like Node.js.
1. **Clone the Project:** Download or clone the repository using:
   `git clone https://github.com/your-username/repo-name.git`
2. **Run the App:** Simply navigate to the project folder and double-click **`index.html`** to open it in your preferred web browser (Chrome, Firefox, or Edge).
3. **Pro Tip:** If you are using VS Code, you can right-click `index.html` and select **"Open with Live Server"** for the best development experience.

---

### 📂 Project Structure & Core Logic
- `index.html` & `style.css`: The visual foundation and glassmorphism styling of the assistant.
- `app.js`: Manages the message flow, DOM interactions, and UI response logic.
- `brain.js`: The core engine responsible for Fuse.js initialization, scoring, and stop-word filtering.
- `data.js`: The primary 20k+ row Turkish knowledge base that powers the bot's intelligence.
